# AHR Platform — Content Consumption Experience

## السؤال الذي تجيب عنه هذه الوثيقة
كيف يُختبَر استهلاك المحتوى الفعلي (نص، وسائط) من قِبل المستخدم؟

## مبادئ الاستهلاك

1. **القراءة دون انقطاع**: النص الأساسي (سيرة، وصف عمل) يُقدَّم متصلاً وقابلاً للقراءة دون تجزئة مصطنعة تخدم غرضًا غير القراءة نفسها.
2. **الوسائط داعمة لا بديلة**: أي Media (صورة، صوت، فيديو) يدعم فهم الكيان المرتبط به (Work، Person، Event)، ولا يحل محل النص التوثيقي أو يُقدَّم بمعزل عن سياقه (اتساقًا مع Data Integrity Rules — Phase 4: Media تنتمي دائمًا لكيان آخر).
3. **إفصاح واضح لحالة المحتوى**: محتوى غير مكتمل التوثيق أو قيد المراجعة يُقدَّم بإشارة واضحة أثناء الاستهلاك، لا بعد انتهاء القراءة فقط.
4. **تجربة استهلاك متسقة عبر أنواع المحتوى**: قراءة سيرة Person وقراءة وصف Work تتبعان نفس منطق العرض الأساسي (Information Presentation)، مع اختلاف التفاصيل النوعية فقط.

## تجربة الوسائط تحديدًا

- الصوت والفيديو يبدآن بسياق تعريفي مختصر قبل المحتوى نفسه (ما هذا؟ ولمن؟).
- الصور المرتبطة بعمل أو شخص تُعرض مع الإشارة لمصدرها إن كانت من Press أو أرشيف خارجي (Archive Model — Phase 4).

## ما لا تتضمنه هذه الوثيقة

- لا تصميم مشغل الوسائط أو تخطيط الصفحة فعليًا (Design System Foundations).
- لا تحدد صيغ الملفات التقنية (Technical Architecture).
