# AHR Platform — Navigation Architecture

## السؤال الذي تجيب عنه هذه الوثيقة
كيف يشعر المستخدم أثناء تنقّله بين أقسام المنصة؟ هذه الوثيقة لا تعيد تعريف مستويات التنقل أو عمقه الهرمي (تلك في Navigation System — Phase 3)، بل تصف **الجودة التجريبية** لذلك التنقل.

## مبادئ تجربة التنقل

1. **الاستمرارية المكانية (Spatial Continuity)**: يجب أن يشعر المستخدم دائمًا بموقعه الحالي ضمن البنية (اتساقًا مع Sitemap — Phase 3)، دون الحاجة لتذكّر المسار يدويًا.
2. **الرجوع الآمن**: أي خطوة تنقّل قابلة للتراجع عنها بثقة، دون فقدان سياق أو بيانات كان المستخدم بصددها.
3. **الإشارة الواضحة للسياق الحالي**: يعرف المستخدم دائمًا في أي براند أو قسم هو (Sub-Brand، وفق Brand Hierarchy — Phase 2)، لا يشعر بالتيه بين Academy وArchive وCreative Network.
4. **التنقل السياقي غير المزعج**: الروابط ذات الصلة (Contextual Navigation — Phase 3) تُقدَّم كدعوة استكشاف، لا كإلهاء عن المهمة الأساسية للمستخدم.

## تجربة التنقل حسب نوع الجهاز (مفاهيميًا)

بصرف النظر عن التصميم الفعلي، مبدأ التنقل ثابت: نفس وضوح الموقع ونفس سهولة الرجوع، سواء بحركة سحب، نقرة، أو تمرير — التفاصيل التقنية لكل جهاز تُترك لاحقًا.

## ما لا تتضمنه هذه الوثيقة

- لا تعيد تعريف مستويات التنقل أو حدود العمق الهرمي (Navigation System — Phase 3).
- لا تتضمن تصميم القوائم أو الأزرار فعليًا (Design System Foundations).
