# AHR Platform — Products

## السؤال الذي تجيب عنه هذه الوثيقة
ما هي المنتجات التي يقدّمها AHR فعليًا لمستخدميه اليوم، وما فئات المنتجات المستقبلية، وكيف ترتبط ببعضها؟

الفرق بين هذه الوثيقة ووثيقة Ecosystem: **Ecosystem** تصف المكونات البنيوية للمنصة (من يملك ماذا، من يعتمد على من). **Products** تصف ما يُقدَّم فعليًا للمستخدم كمخرج قابل للاستخدام.

## المنتجات الحالية

| المنتج | المكوّن المصدر | يُقدَّم عبر |
|---|---|---|
| الأرشيف الرقمي العام (سيرة، أعمال، جوائز، وسائط) | Archive | Website |
| التدريب والتقييم الصوتي | AHR Academy | جلسات مباشرة + تقارير موثقة |
| الدورات التعليمية المنظّمة | AHR Academy | منصة تعليمية تابعة للأكاديمية |

## فئات المنتجات المستقبلية

| الفئة | المكوّن المصدر | الحالة |
|---|---|---|
| شبكة تواصل إبداعي فعلية (مطابقة فنانين/منتجين) | AHR Creative Network | لم تُبنَ بعد — Backlog حتى اعتماد Phase الخاص بها |
| مساعد ذكاء اصطناعي تفاعلي (طالب/مدرّب) | AHR AI Platform | قيد التصميم المعماري |
| تطبيق موبايل | AHR Core (واجهة إضافية) | لم يُعتمد كـ Phase مستقل بعد |
| منتجات عضوية (Membership) | AHR Creative Network / AHR Core | فكرة مطروحة، غير معتمدة |

## العلاقة بين المنتجات

كل المنتجات، حالية أو مستقبلية، تُبنى فوق نفس بيانات AHR Core ولا تُنشئ سجلات مستقلة للأشخاص أو الأعمال. منتج جديد يُضاف كواجهة أو خدمة إضافية فوق البيانات القائمة، لا كنظام منفصل.

## ما لا تتضمنه هذه الوثيقة

- لا تتضمن تسعيرًا أو نموذج عمل تجاري.
- لا تصف واجهات المستخدم أو تدفقات الاستخدام (ذلك موضوع UX/UI لاحقًا).
