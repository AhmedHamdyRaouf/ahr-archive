# AHR Platform — Ecosystem

## السؤال الذي تجيب عنه هذه الوثيقة
ما هي المكونات الرسمية للمنصة؟ كيف تترابط؟ من يملك كل مكون؟ وما تبعية كل واحد للآخر؟

## المكونات الرسمية

| المكوّن | الوصف | الملكية |
|---|---|---|
| **AHR Core** | الطبقة الأساسية المشتركة: الهوية، الحوكمة، القاعدة المركزية للبيانات | يملكها ويحكمها AHR مباشرة — لا تُستهلك بمعزل عن باقي المكونات |
| **Personal Brand** | الهوية العامة لأحمد حمدي رؤوف | تابع مباشر لـ AHR Core |
| **Archive** | التوثيق الرقمي للأعمال والمسيرة والعلاقات المهنية | يعتمد على AHR Core، ويُعرض عبر Website |
| **AHR Academy** | النشاط التعليمي | يعتمد على AHR Core لبيانات الأشخاص والمحتوى، له بيانات إضافية خاصة به (طلاب، دورات) |
| **AHR Creative Network** | شبكة التواصل الإبداعي | يعتمد على AHR Core وعلى بيانات Archive (السجل الموثّق يبني الثقة داخل الشبكة) |
| **AHR AI Platform** | الطبقة الذكية الخادمة | يخدم كل المكونات أعلاه، ولا يوجد كمنتج مستقل قائم بذاته |
| **Website** | واجهة العرض العامة | مخرج (Output) يستهلك بيانات AHR Core وArchive، وليس مكونًا مستقلًا بذاته |

## العلاقات

```
AHR Core (الهوية + القاعدة المركزية)
   │
   ├── Personal Brand
   ├── Archive ──────────────┐
   ├── AHR Academy            │  يُستهلك عبر
   ├── AHR Creative Network   │  Website / واجهات العرض
   │                          │
   └── AHR AI Platform ───────┘ (يخدم كل ما سبق)
```

## قاعدة التبعية

لا يوجد مكوّن يمتلك بيانات مستقلة عن AHR Core فيما يخص الهوية (الأشخاص، الأعمال، المؤسسات). أي بيانات إضافية خاصة بمكوّن معيّن (مثل بيانات الطلاب في Academy) تُبنى **فوق** AHR Core، لا بمعزل عنه.

## ما لا تتضمنه هذه الوثيقة

- لا تصف المنتجات الفعلية القابلة للاستخدام من قبل المستخدم النهائي (ذلك موضوع Products).
- لا تتضمن أي تفاصيل تقنية عن قواعد البيانات أو الـ APIs (ذلك موضوع Technical Architecture وDatabase Architecture لاحقًا).
