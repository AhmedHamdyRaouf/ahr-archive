# AHR Platform — User Journeys

## السؤال الذي تجيب عنه هذه الوثيقة
ما المسارات الأساسية التي يسلكها كل نوع مستخدم (المعتمد في Users — Phase 1) عبر بنية المعلومات لتحقيق هدفه؟

هذه مسارات **مفاهيمية** تصف تتابع الخطوات، لا تصميم الشاشات (UX/UI لاحقًا).

## المسارات الرسمية

| نوع المستخدم | الهدف | المسار المفاهيمي |
|---|---|---|
| **الزائر (Visitor)** | اكتشاف الأرشيف والتحقق من مصداقيته | Home → Works / Recognition → Work Detail (يرى Contributions موثقة) |
| **الطالب المحتمل** | فهم ما تقدّمه Academy قبل التسجيل | Home → Academy (مدخل عام) → محتوى تعريفي بالمنهج والمدرّب |
| **الطالب المسجّل** | متابعة تقدّمه التعليمي | دخول إلى منصة Academy الداخلية (خارج نطاق Sitemap العام) |
| **العضو الإبداعي المحتمل** | فهم قيمة الانضمام لـ Creative Network | Home → Creative Network (مدخل عام) → أمثلة من الأرشيف الموثّق كدليل ثقة |
| **الباحث/الصحفي** | التحقق من معلومة أو تغطية إعلامية | Works / Recognition → Work Detail → مصادر التوثيق المرتبطة |
| **المسؤول (Administrator)** | إدارة المحتوى | دخول إلى Dashboard (خارج نطاق Sitemap العام، يُفصَّل في Dashboard Structure) |

## مبدأ المسار الواحد الأقصر

كل مسار في هذا الجدول يجب أن يكون قابلاً للإنجاز دون الرجوع لأكثر من مستوى تنقل هرمي واحد للخلف (بما يتسق مع قاعدة العمق في Navigation System).

## ما لا تتضمنه هذه الوثيقة

- لا تتضمن تصميم الشاشات أو تدفقات النقر التفصيلية (UX/UI).
- لا تتضمن منطق العمل خلف كل خطوة (Business Logic — Phase 6).
