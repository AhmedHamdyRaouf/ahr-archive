# AHR Platform — Entity Catalog

## السؤال الذي تجيب عنه هذه الوثيقة
ما هي الكيانات المعتمدة رسميًا؟ ما وصف كل واحد ومسؤوليته، وبأي كيانات يرتبط؟ (بلا حقول بيانات بعد — ذلك خارج نطاق هذه الوثيقة بالكامل).

## الكيانات

### Person
**الوصف**: أي فرد داخل منظومة AHR — بغض النظر عن كونه له حساب مستخدم أم لا.
**المسؤولية**: تمثيل هوية فردية واحدة موحّدة، مهما تعددت أدوارها.
**يرتبط بـ**: Contribution (مباشرة)، وعبرها بـ Work وProject وEvent.

### Work
**الوصف**: وحدة إبداعية موثّقة ومنجزة.
**المسؤولية**: تمثيل عمل فني قائم بذاته يمكن الإشارة إليه وربطه بمن ساهم فيه.
**يرتبط بـ**: Contribution، Media، Press، Category/Tag.

### Contribution
**الوصف**: الكيان الرابط الدقيق بين Person وWork أو Project أو Event.
**المسؤولية**: توصيف طبيعة مساهمة شخص معيّن في عمل أو نشاط معيّن — لا يوجد بلا Person، ولا بلا واحد على الأقل من (Work / Project / Event).
**يرتبط بـ**: Person (إلزامي)، Work / Project / Event (واحد منها على الأقل إلزامي).

### Project
**الوصف**: نشاط مستمر لا يُصنَّف كعمل فني منجز منفرد.
**المسؤولية**: تمثيل نشاط ممتد زمنيًا (تدريب، تحكيم، مبادرة) يشارك فيه أفراد عبر Contribution.
**يرتبط بـ**: Contribution، Organization (إن وُجدت جهة راعية)، Media.

### Organization
**الوصف**: أي مؤسسة أو جهة رسمية مرتبطة بالمحتوى.
**المسؤولية**: تمثيل الجهات الخارجية (مؤسسات، قنوات، جهات تحكيم) التي ترتبط بالأعمال أو الجوائز أو المشاريع.
**يرتبط بـ**: Award، Project، Event.

### Award
**الوصف**: جائزة أو تكريم أو عضوية رسمية.
**المسؤولية**: توثيق اعتراف رسمي ممنوح لشخص أو عمل من جهة معينة.
**يرتبط بـ**: Person (عبر Contribution أو ارتباط مباشر)، Organization (الجهة المانحة).

### Event
**الوصف**: فعالية محددة بتاريخ ومكان.
**المسؤولية**: تمثيل حدث زمني واحد يمكن أن يشارك فيه عدة أفراد أو أعمال.
**يرتبط بـ**: Contribution، Organization، Media.

### Media
**الوصف**: أي ملف بصري أو سمعي.
**المسؤولية**: توثيق بصري/سمعي داعم، لا يوجد بمعزل عن كيان آخر يشرحه.
**يرتبط بـ**: Work، Person، Project، Event (لا يوجد Media قائم بذاته دون ربط بأحدها).

### Press
**الوصف**: أي تغطية صحفية أو إعلامية خارجية.
**المسؤولية**: توثيق مصدر خارجي يشير إلى المحتوى الداخلي، لا يستبدله.
**يرتبط بـ**: Person، Work، Event، Organization (الجهة الناشرة).

### Category
**الوصف**: تصنيف هرمي.
**المسؤولية**: تنظيم الكيانات ضمن بنية أب/ابن ثابتة.
**يرتبط بـ**: Work، Project (كما هو معتمد في Content Taxonomy).

### Tag
**الوصف**: وسم وصفي حر غير هرمي.
**المسؤولية**: إضافة خصائص وصفية عابرة للتصنيف الهرمي.
**يرتبط بـ**: أي كيان محتوى دون قيد هرمي.

## قاعدة عدم الاستقلال

لا يوجد كيان (باستثناء Person وOrganization) بلا ارتباط بكيان آخر على الأقل. الكيانات المستقلة كليًا غير مسموح بها معماريًا.

## ما لا تتضمنه هذه الوثيقة

- لا حقول بيانات أو أنواعها (Metadata Model، Future Database Mapping).
- لا تفاصيل العلاقات (Relationship Model).
