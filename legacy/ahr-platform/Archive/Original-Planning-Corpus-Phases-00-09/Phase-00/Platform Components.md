# AHR Platform — Platform Components List

حصر أولي لجميع مكونات المنظومة كما تظهر من الرؤية والأصول الحالية. هذا الحصر **وصفي** لأغراض Phase 0 فقط — التعريف النهائي والعلاقات بين المكونات سيُحسم في Phase 1 (Core Architecture).

| المكوّن | الوصف | الحالة الحالية |
|---|---|---|
| **Personal Brand / Archive** | هوية أحمد حمدي رؤوف وأرشيف أعماله وسيرته | 🟢 مادة موثقة متقدمة (Entities, Content Packages) |
| **AHR Academy** | المنظومة التعليمية (تدريب صوتي، دورات، طلاب) | 🟢 توثيق تفصيلي موجود (CRM, DVE, WordPress) |
| **AHR Creative Network** | شبكة تربط الفنانين والمنتجين | 🔴 مُعرَّفة اسميًا فقط، بلا توثيق مستقل |
| **AHR AI Platform (AHR AI OS)** | الطبقة الذكية التي تخدم كل المكونات | 🟢 معمارية ورؤية وPrompt Engineering موجودة |
| **Website** | الواجهة العامة لعرض الأرشيف | 🟡 نسخة حية موجودة، تحتاج مطابقة مع أحدث محتوى |
| **Database (Core)** | القاعدة المركزية التي تخدم كل المنتجات | 🟢 Architecture وERD وEntities Catalog جاهزون |
| **CRM** | إدارة بيانات الطلاب/الأعضاء | 🟡 موجود لكن بعدة نسخ متعارضة تحتاج توحيد |
| **Vocal Studio** | نشاط تقييم وتدريب صوتي قائم فعليًا | 🟢 تقارير وقاعدة متدربين موجودة |
| **Mobile App** | تطبيق موبايل مستقبلي | ⏳ Backlog — لم تبدأ |

## ملاحظة
هذا الجدول مدخل أولي لـ Phase 1، وليس اعتمادًا نهائيًا للعلاقات الهرمية بين المكونات (مين Parent ومين Child) — تلك تُحسم في Brand Architecture (Phase 2) وCore Architecture (Phase 1).
