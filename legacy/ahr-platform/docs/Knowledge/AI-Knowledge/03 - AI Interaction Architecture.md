# AHR Platform — AI Interaction Architecture

## السؤال الذي تجيب عنه هذه الوثيقة
كيف يظهر الذكاء الاصطناعي ويتفاعل داخل تجربة المستخدم عبر مكونات المنصة المختلفة؟ (مفاهيميًا — لا تصميم واجهة فعلي، ذلك في UX/UI لاحقًا).

## قنوات التفاعل المفاهيمية

| القناة | الوصف |
|---|---|
| **مساعد تفاعلي** | حوار مباشر مع مستخدم (طالب يسأل عن محتوى تعليمي، زائر يستفسر عن عمل موثّق) |
| **اقتراح مضمّن (Inline Suggestion)** | ظهور اقتراح داخل سياق عمل قائم (تصنيف مقترح أثناء إدخال بيانات) |
| **تقرير مولَّد** | مخرج منظم (تلخيص تقييم صوتي) يُراجعه إنسان قبل اعتماده |
| **تنبيه/ملاحظة** | إشارة استباقية لتعارض أو نقص محتمل في البيانات، دون اتخاذ إجراء تلقائي |

## مبدأ الظهور حسب البراند

كل ظهور للذكاء الاصطناعي يتم **داخل** سياق براند قائم (Academy، Creative Network، Archive)، لا كواجهة مستقلة باسم "AHR AI" تخاطب الجمهور مباشرة — اتساقًا مع Brand Relationships (Phase 2) وAI Principles (مبدأ عدم التمثيل المستقل).

## مبدأ التفاعل حسب نوع المستخدم

نوع تفاعل الذكاء الاصطناعي يختلف حسب دور المستخدم (Users — Phase 1):
- مع **الزائر**: شرح وتوضيح لمحتوى عام موثّق فقط.
- مع **الطالب**: مساعدة تعليمية ضمن نطاق تسجيله في Academy.
- مع **المدرّب/المسؤول**: اقتراحات تحليلية تسريعية، تخضع لمراجعتهم قبل اعتمادها.

## ما لا تتضمنه هذه الوثيقة

- لا تصميم واجهة أو شاشة فعلية (UX/UI).
- لا نصوص Prompts أو حوارات فعلية.
- لا تحدد حدود القرار (AI Decision Boundaries).
