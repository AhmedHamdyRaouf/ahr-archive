# AHR Platform v1.0 — Visitor Guide

**Audience:** Any visitor to the public AHR Platform website (no account needed for anything in this guide).
**Status:** 🔒 Final — describes only pages that actually exist in the codebase as of this document.

---

## 1. Language

The site is available in Arabic (`/ar`) and English (`/en`). Switch languages using the language switcher in the site header — the page you're on stays the same, only the language changes. Arabic pages read right-to-left; English pages read left-to-right.

## 2. What You Can Browse

| Page | What's There |
|---|---|
| **Home** (`/`) | An introduction to Ahmed Hamdy Raouf's work |
| **About** (`/about`) | Biography |
| **Works** (`/works`) | Every published Work (songs, albums, theatre, TV series, film, soundtrack, arrangements, choir, concerts) — click any one for its full detail page |
| **Projects** (`/projects`) | Every published Project (training, jury, cultural, educational, choir direction, initiatives) — click any one for its full detail page |
| **Media** (`/media`) | Public photos, audio, and video |
| **Recognition** (`/recognition`) | Awards and press mentions |
| **Search** (`/search`) | Search across the whole Archive |
| **Contact** (`/contact`) | How to get in touch |

## 3. What You Won't Find Yet

- Individual detail pages for People, Events, or Organizations — only Works and Projects have their own page today. (A Person, Event, or Organization mentioned on a Work/Project page is named there, just without its own separate page yet.)
- A way to submit anything through the Contact page directly — it's contact information, not a live form, in this version.
- Any account/login — the public site has no visitor accounts; sign-in is for Administrators managing content, not for browsing.

## 4. Accessibility

The site follows the platform's Accessibility Guidelines: every image has real alt text, every interactive element is reachable by keyboard, status/verification indicators never rely on color alone, and screen readers announce dynamic content changes. If you encounter an accessibility issue, it's a genuine defect — please report it rather than assume it's expected.

## 5. Content Is Still Growing

This platform launches with its content framework fully built and its Archive structure ready, but the actual historical content (real biographical detail, the full catalogue of Works and Projects) is populated over time — see `5. Content Population Framework/` for how that population happens. What you see reflects what has been reviewed and published so far, not necessarily everything that will eventually be here.
