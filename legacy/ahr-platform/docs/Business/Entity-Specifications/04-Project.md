# Entity Specification — Project

**Source lineage:** Entity Catalog, Relationship Model (Phase 4); Content Standards §Projects.

## Description
An ongoing activity not classified as a single completed creative Work.

## Responsibility
Represents a time-extended activity (training, judging, initiative) in which individuals participate via Contribution.

## Relationships
- **Contribution** — mandatory, at least one.
- **Organization** — optional, if sponsored.
- **Media** — optional.
- **Category / Tag** — optional.

## Content Standard
- **Required:** bilingual title, project type (Category — e.g. training, judging, cultural activity, educational activity, choir management, initiative), at least one linked Contribution.
- **Optional:** bilingual description, linked Organization, Tags, linked Media.
- **Writing standard:** same factual, concise standard as Works — explains what the activity is and its documented timeframe, not its impact in subjective terms.
- **Quality requirement:** same "no orphan" rule as Works — a Project needs at least one documented participant via Contribution.

Standard Draft → Review → Verified → Published → Archived sequence.
