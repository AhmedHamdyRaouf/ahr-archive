# Entity Specification — Work

**Source lineage:** Entity Catalog, Relationship Model (Phase 4); Content Standards §Works.

## Description
A documented, completed creative unit.

## Responsibility
Represents a standalone artistic work that can be referenced and linked to its contributors.

## Relationships (Mandatory unless noted)
- **Contribution** — mandatory, at least one.
- **Media** — optional, supporting visual/audio material.
- **Press** — optional, media coverage.
- **Category / Tag** — optional classification.
- **Parent Work** — optional, for a compound work made of smaller ones.

## Content Standard
- **Required:** bilingual title, work type (Category — e.g. song, album, theatrical piece, TV series, film, film score, arrangement, choir, live concert), at least one linked Contribution.
- **Optional:** bilingual description, Tags, linked Media, linked Press, linked parent Work, a public identifier/slug.
- **Writing standard:** a concise, factual, dignified description — no promotional language, no unverifiable claims. Two to three sentences is typically sufficient; length is never a proxy for quality.
- **Quality requirement:** never published without a Contribution — an "orphan" Work with no documented contributor is not a complete archive entry.

## Lifecycle
Standard Draft → Review → Verified → Published → Archived sequence; entry to Review requires the mandatory Contribution to already exist.
