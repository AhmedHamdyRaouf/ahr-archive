# Entity Specification — Event

**Source lineage:** Entity Catalog, Relationship Model (Phase 4); Content Standards §Events.

## Description
A specific activity fixed to a date and place.

## Responsibility
Represents a single point-in-time occurrence in which multiple people or works may have participated.

## Relationships
- **Contribution** — mandatory, at least one (who participated).
- **Organization** — optional, as organizer.
- **Media** — optional.

## Content Standard
- **Required:** bilingual title, a specific date, a specific place, at least one linked Contribution.
- **Optional:** bilingual description, linked Organization, linked Media.
- **Writing standard:** factual — what happened, when, where, and who documented-ly participated.
- **Quality requirement:** an Event without a fixed date and place is not a complete Event entry — this is what distinguishes it conceptually from a Project.

## Lifecycle
Standard Draft → Review → Verified → Published → Archived sequence.
