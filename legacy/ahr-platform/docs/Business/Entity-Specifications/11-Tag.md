# Entity Specification — Tag

**Source lineage:** Entity Catalog, Relationship Model (Phase 4).

## Description
A free, non-hierarchical descriptive label.

## Responsibility
Adds cross-cutting descriptive attributes that do not fit the fixed hierarchical Category structure.

## Relationships
- Any content entity — without hierarchical constraint.

## Content Standard
Like Category, Tag is a controlled/open vocabulary label rather than authored content; it inherits the entity-agnostic baseline in `06-content-standards.md`. Unlike Category, new Tag values may be introduced more freely, but see `Terminology/04-terminology-dictionary.md` for the required distinction between Category and Tag usage — using the wrong one is a governance error, not a stylistic slip.
