# CMS Rules

Rules governing how content is authored, moderated, and published through the CMS. Combines:
- `Package 02 - CMS.md` — package-level CMS scope and capability boundaries.
- `07 - CMS UI.md` — CMS interface behavior.
- `03 - CMS API.md` — CMS API surface and contract.
- `CTO-Deliverable-05-CMS.md` — as-built CMS implementation record.

**Cross-reference:** The underlying business logic these documents implement is defined in `Business Rules/` (Publication Rules, Verification Logic, Moderation Logic, Ownership Rules, Collaboration Logic, Entity Lifecycles). Where a CMS rule and a Business Rule ever conflict, `Business Rules/` is authoritative — the CMS documents describe how the rule is enforced in software, not what the rule is.
