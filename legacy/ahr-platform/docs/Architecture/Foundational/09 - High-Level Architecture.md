# AHR Platform — High-Level Architecture

## السؤال الذي تجيب عنه هذه الوثيقة
ما هي الطبقات المفاهيمية الكبرى التي تتكون منها المنصة؟ هذه وثيقة مفاهيمية فقط — لا تتضمن أي API أو Schema أو أدوات تقنية بعينها (تلك موضوع Database Architecture وTechnical Architecture لاحقًا).

## الطبقات الكبرى

```
┌───────────────────────────────────────────────┐
│  طبقة التجربة (Experience Layer)                │
│  Website · تطبيقات مستقبلية · لوحات تحكم        │
└───────────────────┬───────────────────────────┘
                    │
┌───────────────────┴───────────────────────────┐
│  طبقة الذكاء (Intelligence Layer)               │
│  AHR AI Platform — تحليل / اقتراح / مساعدة       │
└───────────────────┬───────────────────────────┘
                    │
┌───────────────────┴───────────────────────────┐
│  طبقة المنتجات (Product Layer)                  │
│  Archive · AHR Academy · AHR Creative Network   │
└───────────────────┬───────────────────────────┘
                    │
┌───────────────────┴───────────────────────────┐
│  طبقة الهوية والحوكمة (Identity & Governance)    │
│  الأشخاص · الأعمال · المؤسسات · القرارات المعتمدة │
└───────────────────┬───────────────────────────┘
                    │
┌───────────────────┴───────────────────────────┐
│  طبقة البيانات المركزية (Core Data Layer)        │
│  AHR Core — مصدر الحقيقة الوحيد لكل شيء          │
└───────────────────────────────────────────────┘
```

## وصف الطبقات

- **طبقة البيانات المركزية**: مصدر الحقيقة الوحيد. كل بيانات الأشخاص والأعمال والمؤسسات تعيش هنا مرة واحدة فقط.
- **طبقة الهوية والحوكمة**: القواعد التي تحدد من يملك ماذا، وكيف تُعتمد القرارات وتُقفل، وكيف تُدار الأدوار المتعددة لنفس الشخص.
- **طبقة المنتجات**: المكونات التي تستهلك البيانات المركزية لتقديم قيمة مباشرة (أرشيف، تعليم، شبكة).
- **طبقة الذكاء**: تخدم كل الطبقات السابقة بالتحليل والاقتراح، دون أن تكون مصدر بيانات مستقلاً أو صاحبة قرار نهائي.
- **طبقة التجربة**: الواجهات التي يتفاعل معها المستخدم النهائي، وهي الطبقة الوحيدة القابلة للتغيير أو الاستبدال دون التأثير على الطبقات الأدنى.

## مبدأ الاتجاه الواحد

التبعية تسير من أعلى لأسفل فقط: طبقة التجربة تعتمد على ما تحتها، لا العكس. لا يجوز لطبقة البيانات المركزية أن تعتمد على تفاصيل خاصة بواجهة عرض معينة.

## ما لا تتضمنه هذه الوثيقة

- لا تحدد نوع قاعدة البيانات أو لغة البرمجة أو الأدوات (Technical Architecture).
- لا تتضمن مخطط الجداول أو العلاقات التفصيلية (Database Architecture).
- لا تتضمن أي API أو بروتوكول اتصال.
