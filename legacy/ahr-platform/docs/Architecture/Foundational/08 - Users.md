# AHR Platform — Users

## السؤال الذي تجيب عنه هذه الوثيقة
من هي أنواع المستخدمين الرسمية في AHR؟ وما مسؤولية وصلاحيات وحدود كل نوع؟

## أنواع المستخدمين

| النوع | الوصف | الصلاحيات الأساسية | الحدود |
|---|---|---|---|
| **الزائر (Visitor)** | أي شخص يتصفح الأرشيف أو الموقع دون تسجيل | قراءة المحتوى العام فقط | لا وصول لأي بيانات غير منشورة رسميًا |
| **الطالب (Student)** | مسجّل في نشاط تعليمي عبر AHR Academy | الوصول لمحتوى تعليمي خاص، تقارير تقييمه الشخصية | لا يرى بيانات طلاب آخرين |
| **المدرّب (Trainer)** | يقدّم تدريبًا أو تقييمًا داخل Academy | إدخال تقييمات، الوصول لبيانات طلابه | لا صلاحية تعديل بيانات الأرشيف العام أو الهوية المركزية |
| **العضو الإبداعي (Creative Member)** | فنان/منتج مسجّل ضمن Creative Network | عرض ملفه المهني، التواصل ضمن الشبكة | عضويته مبنية على بيانات موثقة، لا يُنشئ سجلات هوية مستقلة |
| **المسؤول (Administrator)** | يدير المحتوى والبيانات نيابة عن صاحب المنصة | تعديل ونشر وأرشفة البيانات وفق الصلاحيات الممنوحة | يعمل ضمن حدود Core Principles، لا يتجاوز القرار البشري النهائي لصاحب المنصة |
| **صاحب المنصة (Platform Owner)** | أحمد حمدي رؤوف | صاحب القرار النهائي في كل شيء | لا حدود صلاحية — هو مصدر الاعتماد الوحيد |
| **الطبقة الذكية (AI System)** | AHR AI Platform كفاعل داخل النظام | تحليل، اقتراح، تلخيص، مساعدة | لا صلاحية نشر أو حذف أو اتخاذ قرار نهائي بمفردها |

## علاقة أنواع المستخدمين بالمنظومة

كل نوع مستخدم (باستثناء الزائر) مرتبط بسجل واحد داخل AHR Core، حتى لو كان له أكثر من دور (مثال: عضو Creative Network يمكن أن يكون أيضًا مدرّبًا في Academy — بسجل واحد لا سجلين).

## ما لا تتضمنه هذه الوثيقة

- لا تتضمن تفاصيل تسجيل الدخول أو الأمان التقني (ذلك موضوع Technical Architecture لاحقًا).
- لا تتضمن تصميم واجهات كل نوع مستخدم (ذلك موضوع UX/UI).
