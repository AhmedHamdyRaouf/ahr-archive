# AHR Platform — Project Definition

## اسم المشروع
**AHR Platform**

## طبيعة المشروع
AHR ليس موقعًا شخصيًا، وليس منتجًا واحدًا.

AHR هو **منصة (Platform)** تضم عدة منتجات مترابطة تحت هوية واحدة، قاعدة بيانات واحدة، ومنظومة ذكاء اصطناعي واحدة تخدمها جميعًا.

الموقع الشخصي (Website) هو **أحد مخرجات المنصة**، وليس المنصة نفسها.

## نطاق المشروع (Scope)

**داخل النطاق:**
- الهوية الشخصية لأحمد حمدي رؤوف (Personal Brand / Archive)
- AHR Academy (المنظومة التعليمية)
- AHR Creative Network (شبكة التواصل الإبداعي)
- AHR AI Platform (منظومة الذكاء الاصطناعي الداخلية)
- قاعدة البيانات المركزية التي تخدم كل ما سبق
- الموقع الإلكتروني كواجهة عرض للأرشيف

**خارج النطاق حاليًا (Backlog):**
- أي فكرة أو منتج جديد لم يُعتمد بعد ضمن الـ Roadmap الرسمي
- تطبيق الموبايل (مؤجل لحين اعتماد مرحلة مستقلة له)
- أي توسع جغرافي أو لغوي غير العربية/الإنجليزية

## مالك المشروع وصاحب القرار
أحمد حمدي رؤوف — صاحب القرار النهائي في كل مرحلة ووثيقة.
