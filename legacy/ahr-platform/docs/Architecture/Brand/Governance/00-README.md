# Governance

Who decides what, how a decision gets locked, and how this Knowledge Base itself is maintained.

- `08-governance.md` — the Knowledge Foundation's consolidated governance model (primary reference).
- `Project Rules.md`, `Documentation Workflow.md` — Phase 0 working rules and the original documentation process.
- `09 - Brand Governance.md` — brand-specific governance (Phase 2).
- `10 - Information Governance.md` — information-architecture governance (Phase 3).
- `09 - Delivery Governance.md` — delivery/release governance (Phase 9).

Any new entity, field, page, AI workflow, or feature that is not traceable to `Domain Model/` or `Business Rules/` requires a governance decision recorded here before it becomes part of AHR — not after.
