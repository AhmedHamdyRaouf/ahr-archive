# Domain Model

The business concepts (not database tables) AHR is built from, and how they relate.

- `02-domain-model.md` — the Knowledge Foundation's consolidated domain model (primary reference).
- `01 - Data Architecture.md` through `10 - Future Database Mapping.md` — the original Phase 4 corpus this was synthesized from (Entity Catalog, Relationship Model, Identity Model, Data Lifecycle, Data Integrity Rules, Archive Model, Metadata Model, Identifier Strategy).

**See also:** `Entity Specifications/` for a per-entity working reference built from this folder plus the content standards.
