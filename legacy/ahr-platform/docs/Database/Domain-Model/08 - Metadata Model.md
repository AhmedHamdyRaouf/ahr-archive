# AHR Platform — Metadata Model

## السؤال الذي تجيب عنه هذه الوثيقة
ما البيانات الوصفية المشتركة التي يحملها كل كيان بصرف النظر عن نوعه؟ (مفاهيميًا فقط، بلا أنواع بيانات تقنية).

## البيانات الوصفية المشتركة

| البيان الوصفي | الوصف المفاهيمي |
|---|---|
| **Status** | الحالة الحالية للكيان ضمن دورة حياته (Draft / Review / Published / Archived) وفق Data Lifecycle |
| **Visibility** | مدى ظهور الكيان (عام، مقيّد لسياق معيّن مثل Dashboard، مخفي) |
| **Language** | اللغة أو اللغات التي تتوفر بها بيانات الكيان (عربي/إنجليزي، وفق مبدأ الاتساق ثنائي اللغة) |
| **Created Date** | تاريخ الإنشاء الأولي للكيان |
| **Updated Date** | تاريخ آخر تعديل جوهري |
| **Verification Status** | حالة موثوقية الكيان (موثّق، مُبلَّغ ذاتيًا، قيد المراجعة، مؤرشف) وفق Identity Model |
| **Source** | مصدر البيانات الأصلي (وثيقة أرشيف، إدخال يدوي، مصدر خارجي موثّق) |
| **Ownership** | الجهة أو الشخص المسؤول عن دقة الكيان وصيانته |
| **Rights** | طبيعة الحقوق المرتبطة بالكيان (خصوصًا لكيانات Media وPress) |

## مبدأ المشاركة العابرة للكيانات

هذه البيانات الوصفية لا تُعرَّف من جديد لكل نوع كيان على حدة؛ هي طبقة مشتركة تُطبَّق على أي كيان في Entity Catalog دون استثناء، لضمان اتساق طريقة إدارتها.

## ما لا تتضمنه هذه الوثيقة

- لا تحدد نوع البيانات التقني لكل حقل (نص، تاريخ، قائمة) — Future Database Mapping.
- لا تحدد من يملك صلاحية تعديل كل بيان وصفي (Business Logic).
