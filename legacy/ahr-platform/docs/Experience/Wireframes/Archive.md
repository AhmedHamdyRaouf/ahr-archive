# Wireframes — Archive (Domain Layer)

**Screens:** None, by design.

Archive is a domain/service layer with no UI of its own — its "interface" is expressed entirely through CMS (authoring) and Website (presentation). This file exists only to make that boundary explicit within the Wireframes index, not to invent screens where none exist. Archive's validation errors (`MISSING_CONTRIBUTION`, `INVALID_STATUS_TRANSITION`, `TAXONOMY_DOMAIN_MISMATCH`) surface as CMS's error states — see `Wireframes/CMS.md`.
