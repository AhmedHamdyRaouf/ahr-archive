# AHR Platform — UX Principles

## السؤال الذي تجيب عنه هذه الوثيقة
ما المبادئ الثابتة التي تحكم تجربة المستخدم عبر AHR بأكمله؟ وكيف ترتبط وثائق Phase 7 ببعضها؟

## الفرق بين Phase 7 وPhase 3

**Information Architecture (Phase 3)** حددت **ماذا يوجد** (الصفحات، التصنيف، البحث، مسارات المستخدم كخطوات). **UX/UI System (Phase 7)** تحدد **كيف يُعاش ويُحَس** ذلك البنيان — الجودة الشعورية والتفاعلية للتجربة، لا إعادة تعريف بنيتها.

## خريطة وثائق Phase 7

| # | الوثيقة | تجيب عن |
|---|---|---|
| 02 | Navigation Architecture | كيف يشعر المستخدم بالتنقل، لا بنيته الهرمية (تلك في Phase 3) |
| 03 | Information Presentation | كيف يُعرَض المحتوى بصريًا من حيث التسلسل والتجميع والتأكيد |
| 04 | User Journeys | ما جودة التجربة عبر كل خطوة من المسارات المعتمدة في Phase 3 |
| 05 | Entry Points | كيف يصل المستخدم لأول مرة، وما انطباعه الأول |
| 06 | Interaction Patterns | كيف يتلقى المستخدم استجابة لأفعاله |
| 07 | Search & Discovery Experience | ما جودة تجربة البحث، لا منطق ترتيبه (ذلك في Phase 3) |
| 08 | Notification Experience | كيف ومتى يُبلَّغ المستخدم بأي شيء |
| 09 | Content Consumption Experience | كيف يُختبَر استهلاك المحتوى الفعلي (نص، وسائط) |
| 10 | Design System Foundations | الأسس البصرية (فئات لا قيمًا نهائية) |

## المبادئ العليا

1. **الوضوح قبل الجمال**: أي قرار تجربة يُختبر أولاً بوضوح الفهم، قبل الجاذبية البصرية — اتساقًا مع Identity Principles (Phase 2).
2. **الثقة عبر الشفافية**: أي تجربة تعرض محتوى ذكاء اصطناعي تُوضّح ذلك صراحة (اتساقًا مع AI Explainability — Phase 5)، لا تُخفيه.
3. **التكافؤ بين اللغتين**: تجربة المستخدم العربية والإنجليزية متكافئتان في الجودة والوضوح، لا نسخة أساسية وأخرى ثانوية.
4. **الاحتكاك الأدنى للثقة**: خطوات التحقق والمراجعة البشرية (Phase 6) تُقدَّم كجزء طبيعي من التجربة، لا كعائق يُشعر المستخدم بالبيروقراطية.
5. **الاتساق عبر البراندات**: تجربة أي Sub-Brand تحمل نفس الجودة الأساسية لتجربة AHR كـ Master Brand (Brand Relationships — Phase 2)، حتى مع اختلاف السياق.

## ما لا تتضمنه هذه الوثيقة

- لا تعيد تعريف بنية الصفحات أو التصنيف (Phase 3).
- لا تعيد تعريف قواعد العمل أو الصلاحيات (Phase 6).
- لا تتضمن قيمًا بصرية نهائية (ألوان، خطوط فعلية) — Design System Foundations تحدد الفئات فقط.
