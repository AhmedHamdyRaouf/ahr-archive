# الصور

## تسمية الملفات
`<رقم السجل>_<وصف-قصير-بالإنجليزي>.jpg`

أمثلة:
- `MA-0028_feen-albi-premiere.jpg` (صورة مسجلة في Media_Assets)
- `P-0158_mostafa-kamar.jpg` (صورة شخص)
- `W-0079_feen-albi-poster.jpg` (أفيش عمل)

## القواعد
- كل صورة تُسجَّل في ورقة Media_Assets (وجدول media_assets) وفيها مسار الملف.
- لا تُرفع صور الكارنيهات أو البطاقات الشخصية.
- صور الأطفال تبقى في المستودع الخاص فقط ولا تُستخدم علناً قبل مراجعة أحمد.
- الحد الأقصى 100 ميجا للملف.
